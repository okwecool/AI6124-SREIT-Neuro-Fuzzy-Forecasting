# 第二版 A+B 最小实验：实现方案

**日期：**2026-11-04。**状态：**开发前方案，尚未启动任何第二版拟合。  
**依据：**[第二版改进假设](improvement_hypotheses_2026-11-04_zh.md)及[冻结结果事后诊断](frozen_result_diagnosis_2026-11-04_zh.md)。本文件只细化首轮 H1 与 H3；H2/H4/H5/H6 保留为条件分支。第一版最终测试仍是已查看历史，不能用于第二版选择或宣称独立优化。

## 一、实施范围与关键修正

首轮执行 **H1（训练期均值和 Ridge）→ H3（固定 λ=0.1 的局部专家损失）**。H1 即使显示信号很弱，仍允许完成一次 H3，因为 H3 是对项目核心机制的受控检验；之后停止结构搜索，除非出现明确的新开发期证据。两项改动不同时加入新特征、新预测时域或交易阈值。

当前 `src/models.py`、`src/train.py` 已被第一版最终配置记录 SHA-256。新实验只增加 `src/v2/` 模块，不编辑这两个文件、原始数据、第一版预测或 `output/runs/development` 与 `output/final`。第二版目录拟定为 `output/v2/h1/` 和 `output/v2/h3/`；所有运行写独立 manifest、代码／数据哈希和本地 checkpoint。训练入口只允许 `validation_1/2/3`，明确拒绝 `final_holdout`。

旧 `project_eval` 的预测契约只把模型名 `Fuzzy1/2/3` 识别为模糊模型，`export_contract` 也拒绝 `Fuzzy2Local`。因此 H3 **导出 CSV 中保持 `model_id=Fuzzy2, rule_count=2`，而在目录与 manifest 中用 `experiment_id=V2-H3-local-loss-01` 标明变体**。每个变体单独用旧契约核验预测、case、rule；比较器载入后先附加 `experiment_id`，再按 `(experiment_id, fold, seed, window_id)` 对齐。绝不把第一版和 H3 的 `Fuzzy2` 原始 CSV 直接合并，否则会产生重复主键。最终表格显示名为 `Fuzzy2 + local loss`。H1 的确定性模型用 `MeanTrain`、`Ridge`，`rule_count=0, seed=0`。

## 二、H1：先建立简单信息基准

### 数据与拟合

- 复用固定数据快照、`Dataset.ids()`、`Dataset.prepare()` 与六特征 `all`，仅评价原三个开发折的同一 378 个目标日。每折训练期均值使用**该折训练标签**；评价期均值只出现在诊断表中，不能用于预测。
- Ridge 将标准化后的 `20×6` 特征按时间顺序展平为 120 维。输入和目标的缩放由每次拟合自己的训练集确定：选 α 时用内层训练段的 scaler，完整外层重拟合时重新用外层训练集的 scaler。内层停止段只能用于选择 α，不能参与候选拟合。
- 使用 NumPy 的 float64 线性求解，不增加新依赖。目标函数定为 `Σ_i(y_i−b−x_i w)² + α‖w‖²`，截距 `b` 不惩罚；`α∈{0.1,1,10}`。先对设计矩阵逐滞后列和标准化目标做训练内中心化，再解 `(XᵀX+αI)w=Xᵀy`，最后恢复截距。这样 α 的定义不随实现库改变。
- 内层选择标准是**原始收益率单位 RMSE**，与标准化目标的排序等价；数值完全相同时选更大的 α。选定 α 后，外层训练集重新拟合一次，只对该折验证日期输出原始收益率。Ridge 无随机性，不重复造三个种子；共 3 折 ×（3 候选 + 1 重拟合）= **12 次轻量拟合**。

### 对比与停止点

同日期比较 `Z0`、`MeanTrain`、`Ridge` 和第一版保存的 `LSTM32/LSTM3/Fuzzy2/Gate2`。报告每折与 pooled RMSE/MAE、预测与真实收益的均值和标准差、正预测占比、预测／真实相关及方向偏置。`MeanTrain` 和 `Ridge` 是**第二版事后加入的开发参考**，不得写成第一版预注册主基线。

H1 结论只分为“观察到较稳定的超简单模型信息”或“没有观察到”。若均值/Ridge 和旧神经模型都不能在多个开发折稳定胜过 `Z0`，停止广泛特征与容量搜索；仍执行一次 H3 后决定是否结束首轮。

## 三、H3：一次局部损失机制实验

### 训练定义

直接实例化原 `Fuzzy2`，不改变 LSTM、三维投影、两条 Gaussian 规则或两个仿射专家。对训练 batch 的**标准化标签**和专家标准化输出计算文档固定的局部项：

```text
L_mix   = mean_i (Σ_k α_ik e_ik − y_i)²
L_local = (1/2) Σ_k {Σ_i stopgrad(α_ik)(e_ik−y_i)² /
                      [Σ_i stopgrad(α_ik)+1e−8]}
L_train = L_mix + 0.1 L_local
```

`stopgrad` 仅切断局部项到门控权重的直接梯度；全局混合损失仍训练门控，局部项仍能更新专家与共享编码器。优化器、学习率 `0.001`、AdamW 权重衰减 `0.0001`、batch 64、梯度裁剪 1、种子 `11/23/37`、同一种子的内层早停／外层重启重拟合规则沿用第一版。早停**只看内层 `L_mix`**，不用局部项或外层验证表现选择 epoch；manifest 同时记录 `L_mix`、`L_local`、总训练损失和停止集混合 MSE。

首先做一个不进入研究结果的工程核对：在一个开发折和种子上，`λ=0` 的新训练路径应复现第一版 `Fuzzy2` 的 epoch 选择和预测（允许事先写明的浮点容差）；再用小 batch 检查有限梯度、专家与共享表示收到局部梯度，以及全局损失仍能更新门控。之后只运行 **`λ=0.1` 一个新增配置 × 3 折 × 3 种子 = 9 组、18 次内层／外层拟合**。首轮不扫描多个 λ，不加聚类、分离、平衡损失或新特征。

### 必须同时检查的两种失败

当前权重接近 0.5，局部项可能使**两个专家学成相同预测器**；这也会降低抵消，但不产生局部专长。因此每折每种子同时报告：混合输出 RMSE/MAE、训练期定义的各规则高激活样本数与局部专家 MAE、平均最大权重、有效规则样本数、两专家原始输出差距、相反符号比例、`|α₁e₁|+|α₂e₂|` 及贡献抵消率。外层重拟合后，只在该折**外层训练窗口**上推断各规则权重，冻结每条规则的 75% 分位数阈值，再应用到外层验证窗口；有效样本数可另用 `(Σα)²/Σα²` 描述。抵消率须与绝对贡献并列，避免预测接近零时只看比例误判。局部区域不足 20 个评价日只作描述；需要在至少两个折看到**两条规则各自**具有局部误差优势，才能讨论分工。

若只消除了相反输出、但两个专家变得相同，或整体 RMSE/MAE 没有通过门槛，则 H3 **未达成机制与预测双重目标**。这不是训练失败，而是对该局部损失假设的负结果。

## 四、对照、判定和数据边界

H3 的**直接归因对照**是第一版相同折、相同种子的 `Fuzzy2`，九个折／种子配对要求至少六组 RMSE 下降。必要的效果对照另含 `Z0`、`MeanTrain`、Ridge、`LSTM3`、`Gate2`；对确定性参考只按同日期比较，不虚构三个种子。将“最强必要对照”明确定义为**包含原 `Fuzzy2` 在内**的上述参考中，三折开发日期上平均 pooled RMSE 最低者；H1 完成后、H3 运行前记录这个参考。其对应 MAE 是“不恶化超过 1%”的参照。候选需在三种子平均 pooled RMSE 上至少低 1%，且相对于这个固定参考，至少两个开发折的种子平均 RMSE 降低。上述是开发期晋级门槛，不是统计显著性证明；全部逐折差异均保存。

第二版不根据第一版最终测试中的 0.44%、负市场均值、最佳种子或具体亏损日期调整 α、λ、早停、目标或阈值。若 A+B 没有达到门槛，停止这条路线并保留负结果；若达到，也只能称为**值得独立验证的开发候选**。由于目前没有新的长期盲测期，报告中不得把开发折提高写成已证实优化。
