# V6：固定原方案的三维表征预训练试验

**日期：2026-11-05。证据性质：**本实验是在查看 V1—V5 结果后提出的开发期探索。运行前固定的输入、辅助任务、比较和停止条件见[实验合同](v6_representation_contract_2026-11-05.json)。不使用原最终期选择或评价新模型，也没有新的独立盲测。

## 目标与改动边界

目标是提高**原定 Fuzzy-LSTM 完整模型**的下一日 SRT 原始收益预测，而不是仅提高普通 LSTM，也不把新信息来源的效果记作模型效果。保留原 20×6 SRT/STI/SORA 张量、`t` 收盘后预测时点、下一日原始收盘对数收益、LSTM32→`tanh` 三维表示→两条 Gaussian 规则→两个仿射专家，以及原三个开发折和种子 11/23/37。

**唯一新增的主要因素是训练前辅助任务。**在各训练前缀内，将 20 日窗口最后五个**已发生的历史日**中三项 SRT 派生特征置为训练均值（缩放后为零），保留 STI 和已公布 SORA；临时线性头从同一三维表示重建这五个历史日的 SRT 日收益。固定训练 20 个 epoch，不用停止段挑选辅助轮数；临时头在主任务训练和推理时移除。内层预训练只用内层拟合窗口；外层重训的预训练只用完整外层训练窗口。不引入 CLR、海外行情、公告预测偏移或新标签。

四组新运行：随机冻结 Fuzzy2 表示、预训练后冻结 Fuzzy2 表示、预训练后按原流程微调完整 Fuzzy2、相同预训练后微调普通 LSTM3。历史 V1 的 Fuzzy2、LSTM3、Gate2 与 Z0 是同数据同日期参考。每组新模型 `3折×3种子=9` 次内外层运行，共 **36 组下游运行**；每折每种子各有内层和外层预训练，共 **18 次辅助拟合**。下游采用原 AdamW、标准化标签、最后 15% 内层停止、同种子外层重启重训。新增辅助训练消耗额外算力，因此这是训练方法扩展，不称为完全相同训练预算。

## 开发期预测结果

神经模型先对每个种子的 378 个不同目标日计算 pooled 指标，再平均三个种子；Z0 是一个确定性参考。

| 方法 | RMSE | MAE |
| --- | ---: | ---: |
| **Z0** | **0.009431** | **0.006290** |
| 原 Gate2 | 0.009456 | 0.006353 |
| 原 LSTM3 | 0.009473 | 0.006387 |
| 原 Fuzzy2 | 0.009489 | 0.006385 |
| 随机冻结表示 Fuzzy2 | 0.009494 | 0.006382 |
| 预训练冻结表示 Fuzzy2 | 0.009511 | 0.006451 |
| **预训练并微调 Fuzzy2** | **0.009528** | **0.006458** |
| 预训练并微调 LSTM3 | 0.009585 | 0.006509 |

主候选预训练 Fuzzy2 相对原 Fuzzy2 **差 0.42% RMSE**，相对 Z0 **差 1.03%**；仅一个开发折的种子平均 RMSE 优于 Z0，和原 Fuzzy2 的九组同折同种子比较中只赢 **5/9**。因此事先固定的 1% 候选门槛和约 3% 实质改善目标均未通过。预训练普通 LSTM3 也未得到增益，不能把本轮写成“普通 LSTM 优化，模糊层跟不上”。

| RMSE | 第一折 | 第二折 | 第三折 |
| --- | ---: | ---: | ---: |
| Z0 | 0.009828 | 0.007270 | 0.010787 |
| 原 Fuzzy2 | 0.009871 | 0.007286 | 0.010888 |
| 预训练 Fuzzy2 | **0.009772** | 0.007687 | 0.010800 |

本轮对第一折有益，但第二折明显恶化。九次内层辅助预训练的首轮/末轮平均 MSE 从约 **1.146 降至 0.937**，却没有改善下游。预训练冻结 Fuzzy2 比随机冻结 Fuzzy2 的 RMSE 更差，说明该辅助任务尚未提供可稳定迁移的预测表示。平均最大规则权重由随机冻结模型约0.531升至预训练 Fuzzy2 约0.620，但权重更分开并不等于局部预测更准确。

将三个除息目标日与其余375日作**事后诊断**：预训练 Fuzzy2 的非除息日 RMSE 约0.009307，原 Fuzzy2约0.009246，Z0约0.009170；三个除息日上预训练 Fuzzy2 的误差反而小一些。事件仅三天，不能把这一点解释为学会分派机制，也不能据此改选模型。

## 停止判断与下一步边界

**结束这一个“遮盖最后五日 SRT 特征并重建历史收益”的辅助任务。**本轮没有改善预定 Fuzzy-LSTM 模型，因此不从这个表示出发继续分阶段专家训练，也不凭较低重建损失或分开的规则权重宣称优化。此结论只否定这一种固定的辅助任务和训练设置，不排除其他表示训练或分阶段专家方法。

如继续探索，应另定一个小范围、与预测目标更相关的表示假设，或先单独核查内层时间选择的稳定性；不能在看过本轮开发结果后调整遮盖长度、辅助 epoch、损失权重，再把最优配置当作本轮预先约定的发现。原最终期已经看过，所有后续数字仍属开发期候选，课程展示必须说明这个边界。
