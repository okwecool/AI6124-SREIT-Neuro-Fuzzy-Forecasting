# 保持基础方案的实质优化探索：实测结果与下一方向

**日期：2026-11-05。**本轮响应“争取比较显著的优化，同时保留老师确定的基础方案”。此前的小型 TSK 筛选建议不作为本轮主路线；本轮直接保留神经编码器与 Gaussian 局部专家，测试训练、预测时域和迁移三个具体假设。

**后续更新：本文是V3阶段的结果与当时建议快照。**海外信息方向后来已执行为[V4](v4_preopen_results_2026-11-05_zh.md)，属于信息/提前量收益；用户进一步明确以相同信息下的模型优化为目标后，它退出主线。当前指导以[模型优化指导第0节](improvement_hypotheses_2026-11-04_zh.md)为准，顺序为表征学习、分阶段专家训练、状态约束前件及配套时间验证。下文历史建议不表示这些事项仍是待执行首选。

**V3阶段结论：本轮仍没有找到可靠的实质提升。**这不是对所有改进可能性的否定。当时据此转向改变信息截止时点；后续已明确，这不能回答用户要求的模型级优化问题。H12/H14的有限负结果也不足以排除新的表示学习和训练机制。

## 1. 基础方案和允许改动的边界

本地协议记载团队批准的结构是：

```text
SRT 历史输入 → LSTM(32) → 三维表示 → 两条 Gaussian 规则 → 两个仿射专家
```

主要资产仍是 SRT，主要目标仍为下一交易日原始收盘对数收益 `log(C_(t+1)/C_t)`。这份协议是当前工作的依据；本轮没有获得或声称获得老师对 V3 的新增批准。所有扩展分别命名并声明，V1 保留为批准方向下的冻结基准实验。

| 改动 | 与基础方案的关系 | 本轮处理 |
| --- | --- | --- |
| 校正历史分派、改变训练求解方式和初始化 | 拓扑、资产、目标保持一致；训练/输入处理扩展 | 已测 H12 |
| CLR 早期历史预训练 | 目标仍是 SRT；增加来源数据、改变训练阶段 | 已测 H14，并标明来源局限 |
| 下一交易日开盘到收盘收益 | 保留资产，但改变预测目标 | 仅做 H13 命名支线，未替换主任务 |
| 预测时点改为次日 08:00，加入已完成海外交易信息 | 主资产、下一收盘目标和神经模糊结构可保留；信息截止时点改变 | V3当时建议，后已执行V4；现为信息支线，不是模型优化主线 |
| 换成其他主资产、用纯 TSK 取代神经模糊结构 | 超出本轮保留基础方案的目标 | 未执行 |

为避免把小数点后的差异包装成改进，本轮将**相对必要强基线至少 3% 的开发期 pooled RMSE 降幅**作为实质提升目标；1% 是值得继续的候选下限，同时要求分折稳定、MAE 不明显退步。它们是本次资源决策标准，不是老师规定的分数线，也不等于统计显著性。

## 2. H12：保留原结构，改用联合神经训练与正则化专家求解

事前合同：[v3_hybrid_training_contract_2026-11-05.json](v3_hybrid_training_contract_2026-11-05.json)。实现：[hybrid_training.py](../src/v3/hybrid_training.py)。

保留 LSTM32、三维表示、两条 Gaussian 规则及两个仿射专家。使用此前已登记的公告基线和分派残差标签；分别测试原始六输入与仅校正 SRT 三列的六输入。与原来不同的是：

1. 在训练数据上归一化潜在坐标，以训练内聚类初始化两个规则的中心和宽度；宽度使用正值参数化，不再沿用旧宽度上界。这改变数值参数化，不增加规则或编码维度。
2. 固定网络前件时，联合求解正则化的仿射后件；梯度通过线性求解更新 LSTM、投影和门控。所有后件系数包括截距均向原始残差零点收缩，固定 λ=0.1。
3. 全批训练、训练段最后 15% 内层早停，再同种子重启并在外层训练段拟合。内层可以选择零残差；选择零残差只代表退回公告基线，不计为优化。
4. 同时训练相同输入、编码器和求解方式的单一线性头与普通非 Gaussian 双专家门控，防止把共同训练改进归因给模糊层。

共 **6 配置 × 3 折 × 3 种子 =54 组运行**。全部使用原 378 个开发日期；三种子先分别算 pooled 指标，再平均。

| 方案 | RMSE | 相对公告基线 |
| --- | ---: | ---: |
| **只用公告 `DivSchedule`** | **0.009170** | — |
| 原 V2 分派残差模糊模型 | 0.009232 | 差 0.67% |
| 新求解 + 原输入 + Gaussian | 0.009247 | 差 0.84% |
| **新求解 + 校正输入 + Gaussian，主候选** | **0.009223** | **差 0.58%** |
| 新求解 + 校正输入 + 线性头 | 0.009181 | 差 0.12% |
| 新求解 + 校正输入 + 普通门控 | 0.009180 | 差 0.10% |

Gaussian 规则的平均最大权重达到约 **0.88**，不再像原模型那样长期接近 0.5。但主候选的折均 RMSE **0/3** 胜过公告基线，非除息日 RMSE 也差 **0.57%**。54 组运行中有 **38 组**选择零残差回退，9 组选择初始随机表示加拟合后件，只有7组选择更新过的神经表示。

**判断：前件分区可以通过训练方法改善，但更清楚的分区没有自动产生更好的条件收益预测。**上述权重统计含零残差回退运行，不能把它当作盈利专家或稳定经济状态的证据。按合同停止这个训练组合，不继续扫描 λ、宽度或种子。

结果与核验：[decision.json](../output/v3/hybrid_training/decision.json)、[比较表](../output/v3/hybrid_training/comparison_pooled.csv)。原论文使用了局部训练和聚类相关机制；我们的测试是自有训练扩展，不是原论文复现，其他市场/时域的论文数字也不能作为本项目预期收益。[Fuzzformer 原文](https://arxiv.org/html/2510.00960v1)

## 3. H13：目标改得更贴近交易执行，是否就有足够信号？

合同：[v3_intraday_screen_contract_2026-11-05.json](v3_intraday_screen_contract_2026-11-05.json)。单独定义 `log(C_(t+1)/O_(t+1))`，仍在 `t` 收盘后预测。不把除息开盘后才买入的持仓算作获得当天分派权益。

在原 378 个日期上，用原/校正六输入分别做零点收缩 Ridge，并比较零收益、训练期均值、前一日同类收益及其反向预测。λ 在内层从固定的三个候选及零预测中选择，最多 24 次小型拟合。

| 日内任务模型 | RMSE |
| --- | ---: |
| **训练期日内收益均值** | **0.008601** |
| 零日内收益 | 0.008726 |
| 原输入 Ridge | 0.008655 |
| 校正输入 Ridge | 0.008700 |

两组 Ridge 分别比该任务的最强简单参考差 **0.64% / 1.16%**，没有通过门槛，因此未据此启动新的神经训练。日内任务的误差数值比收盘到收盘任务低，**不是同一任务的优化**。这也不能排除其他非线性日内关系，只是这次固定筛选没有支持继续的证据。

结果：[decision.json](../output/v3/intraday_screen/decision.json)。

## 4. H14：用更早的 CLR 历史迁移编码器

合同：[v3_transfer_contract_2026-11-05.json](v3_transfer_contract_2026-11-05.json)。没有把 CLR 当成 SRT 的延长价格序列。

- 来源限定为 **2017-10-30 至 2021-09-30**，988 个原始交易日构成 **948 个**完整窗口，所有标签早于本项目 SRT 首日 2021-11-18。
- 源任务使用 CLR 历史分派总收益、五日动量、二十日波动率，预测下一 CLR 总收益。三个种子分别以内层早停选择 **5/3/5 个 epoch**，再重启并在完整源训练段拟合。
- 把前三个同类输入的权重、递归参数和三维投影迁移到 SRT；STI/SORA 输入列保留同种子初始化，源输出头丢弃。SRT 的六输入、下一收盘原始收益目标和双 Gaussian 专家仍保留。
- 这个最小探针冻结编码器，在每个 SRT 训练段重新校准潜在坐标和规则，拟合后件。与**相同流程的随机冻结编码器**及迁移后的线性头/普通门控比较，共54组目标运行。

| SRT 方案 | RMSE |
| --- | ---: |
| **公告基线** | **0.009170** |
| 随机冻结编码器 + Gaussian | 0.009192 |
| **CLR 预训练编码器 + Gaussian** | **0.009176** |
| CLR 预训练编码器 + 线性头 | 0.009178 |
| CLR 预训练编码器 + 普通门控 | 0.009175 |

迁移模糊模型比随机冻结编码器改善 **0.17%**，但仍比公告基线差 **0.07%**，也没有胜过普通门控；其九组运行中七组选择零残差。未达到候选下限。

**判断：本次“下一日源收益预训练 + 冻结迁移”不足以产生显著效果。**它没有检验多任务预训练、其他源资产或目标域微调，不能推广成“迁移学习无效”。来源分派仍是保存的 Yahoo 事件记录，本次没有完成 CLR 全部事件的独立发行人核验，不能声称其已达到 SRT 分派审计水平。

结果：[decision.json](../output/v3/transfer_probe/decision.json)、[比较表](../output/v3/transfer_probe/comparison_pooled.csv)。

## 5. 为什么不把这些结果包装成“已经提升几个百分点”？

新方案叠加公告信息后，确实可以相对原普通 LSTM 或原 Fuzzy 得到更大的百分比。但它们都没有胜过只用公告的简单预测器。因此目前的证据是**新增信息提供了收益，复杂模型大多没有增加收益**。

若只展示相对旧 LSTM 的较大降幅，隐去公告基线，就会掩盖这个区别。用户希望的是有说服力的优化，因此我们不能通过选择较弱对照、改变预测目标量纲、挑选种子或把不交易称为盈利来达成数字目标。

这几轮结果支持“现有信息下的条件平均收益信号可能很弱”这一待检验解释，但没有证明市场不可预测，也没有区分信号不足与表示学习不足。当时据此优先转向新增信息；现在按用户明确的模型级目标修订为：固定原信息，验证表示学习与训练机制，不能用改变信息时点替代模型改进。

## 6. 历史建议：开盘前信息增强（后已执行V4，现非主线）

### 6.1 只声明一个关键变化：预测时点

把这一扩展单独命名为 **Pre-open Information-Enhanced LSTM–Fuzzy**：

```text
原实验：SRT 的 t 日收盘后，用截至该时点的信息预测 t+1 日收盘收益
新扩展：t+1 交易日新加坡时间 08:00，用截至 08:00 已知的信息预测同一个收益目标
```

SRT 资产、`log(C_(t+1)/C_t)` 标签、20 日 LSTM、三维表示、两条 Gaussian 规则和仿射专家均可保留。**预测提前量缩短、信息集扩大**必须写在标题说明、方法表和所有比较图里；不能把新增时段的信息悄悄放回旧“t 收盘”模型，也不能宣称同一信息集下算法突然提高。

SGX 开盘前阶段从 08:30 开始；08:00 是在它之前。美国常规股票交易时段通常在纽约时间 16:00 结束。两地时间安排使部分在 SRT 收盘后发生的海外行情，有机会在次日 08:00 前合法获得；具体历史日必须按真实收盘时间、夏令时、提前收市和休市日逐条判断。[SGX 交易时段](https://www.sgx.com/securities/trading)、[NYSE 官方交易时段](https://www.nyse.com/trade/hours-calendars)

**为什么值得优先测：**这是增加预测时已经发生的新市场观察，而不是从同一条 SRT 历史价格再计算一个指标。我推测它比继续调整专家损失更有机会形成较大预测增益；该推测尚未由本项目实测验证。

### 6.2 最小输入与时点契约

先只选一个美国 REIT 市场代理和一个美国大盘代理，固定后不更换表现不佳的来源。它们的具体品种、历史可用性和数据许可需要在数据审计阶段确认，当前没有下载或拟合这组新数据。

每个来源至少保存：交易所时间、实际常规收盘 UTC 时间、可用时间依据、对应新加坡时间、使用的来源日期及陈旧天数。使用严格的 `available_at <= forecast_time` 对齐：

- **禁止按美股与 SRT 的相同日期字符串直接合并。**美国某日收盘可能已是新加坡次日。
- 美国休市时保留“最近已知来源”的明确状态，跨新加坡假日按预先定义累计，不把尚未结束的海外交易日当成完成数据。
- 除息校正仅使用截至该来源交易时点已经发生的分派；不依赖整段未来回溯复权。
- 08:00 前数据是否实际可获得需核实。若只有估值日期而没有合理的发布时点依据，不直接当成实时已知数据。
- 新输入可作为两条额外的时间序列列；这是输入维度从6到8的命名扩展，需要新模块，不能绕过原冻结模型只允许3/5/6列的限制。

### 6.3 比较必须把“多知道了信息”和“模糊机制”拆开

固定两个信息截止口径：原收盘口径、次日 08:00 口径。在每个口径下给普通线性参考、普通神经头和模糊模型**同样可得的输入**。

1. 先用固定小型 Ridge 检查新时点/新增市场资料是否有增量信号，保留公告基线及原始零收益参考。
2. 有信号后，比较同输入的 `LSTM3`、`Gate2`、`Fuzzy2`，同折同种子同训练预算；目标仍是原下一收盘收益。
3. “08:00 模型优于收盘模型”是**信息/提前量收益**；“08:00 Fuzzy 优于08:00普通头和强线性参考”才支持模糊机制贡献。
4. 继续以约3%作为实质提升目标，同时报告全部分折、MAE、事件/非事件误差及失败配置。原最终期不重新用来选模。

初始神经比较最多 `2 个截止口径 × 3 个头 × 3 折 × 3 种子 =54 组`；是否执行及固定参数应等数据时点审计通过后另写合同。本文只是下一阶段方案，不能当作已预注册或已执行的结果。

### 6.4 这不自动意味着交易盈利

海外信息可能主要改善对次日开盘跳空的预测，而策略到开盘才成交。应把预测收益与可成交的开盘后收益分开；原含成本、分派权益的财富账本仍需使用。即使下一收盘 RMSE 达到3%改善，也不能直接声称能以该信息赚取相同的收益。

## 7. 历史数据备选：固定 t 收盘时点的新增来源（现非模型主线）

优先核实 **SRT 的历史 NAV/标的指数与 ETF 市价之间的偏离**，而不是再增加普通均线。SGX 的 ETF 资料包含 NAV 字段，但本轮未确认完整历史、准确发布时间或可下载接口；基金产品页读取也未成功。这是一项待解决的数据条件，不是已经获得的特征。[SGX ETF 资料入口](https://www.sgx.com/securities/etf-screener)

只能使用预测前已经发布的 NAV，并把 ETF 价格与 NAV 的**同一估值日**配对；NAV 若滞后发布，不能直接拿当天收盘去计算“当天已知折溢价”。若使用标的指数更新估值，也要核实指数发布时间、分派口径、当时成分与权重，不能用当前成分回填过去。

可检验的机制是：折溢价/跟踪偏离与流动性状态是否影响后续收益，模糊专家是否在不同状态有不同局部响应。它比同类 ETF 的单一日收益更贴近 SRT 本身的定价关系，但**尚无本项目数据证明它能提高准确率**。所有基准须获得同样的新信息。

另一条较低优先级是改变源预训练任务，例如加入未来波动率辅助任务后再微调目标编码器。那仍可保留最终 LSTM–Fuzzy 输出结构，但“能学好波动率”不等于“能预测平均收益”；必须作为新假设测试，不能把本轮微小迁移增益当成继续扩大搜索的证据。
