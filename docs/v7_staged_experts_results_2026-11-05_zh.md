# V7：按时间分段训练共同预测与局部专家

**日期：2026-11-05。证据性质：**在看过 V1—V6 后进行的开发期探索。训练前固定的配置、停止和比较标准见[实验合同](v7_staged_experts_contract_2026-11-05.json)。未使用原最终期训练、选择或评价，也没有新盲测。

## 研究问题与训练改动

本轮仍预测 SRT.SI 下一交易日**原始收盘对数收益**，沿用原 20×6 SRT/STI/SORA 历史窗口、收盘后预测时点、三个开发折和种子 11/23/37。完整候选仍是 LSTM32→`tanh` 三维表示→两条 Gaussian 规则→两个仿射专家。相比批准的原始联合训练，**改变的是训练顺序、训练段分配及共享／局部参数求解方法**；这项细节变化应在课程展示中声明。

每个训练前缀按日期切成早期 75% 的**共同学习段**与随后 25% 的**专家校准段**。内层另留原外层训练的末 15% 作停止段；外层重训则在完整外层训练上重新切 75%/25%。所有输入及标签尺度只从共同学习段估计。共同段用固定 10 epoch 学 LSTM、三维投影与岭回归共同系数 `b`，然后冻结编码器、投影、三维坐标标准化和 `b`。专家段在同一三维坐标中，用其较晚的实际残差拟合差异系数 `d`，并只更新 Gaussian 前件或匹配的普通门控。内层停止段选择局部阶段的 0—40 epoch；局部项未比共同预测的停止误差改善至少 0.0001 时保留共同预测。外层用相同种子、切段和所选轮数重训，不读取评价标签。

三组**匹配实验**共用同一共同预测：`V7Common`、`V7StagedGaussian`、`V7StagedGate`。其输出分别为 `q·b` 与 `q·b + (α₁−α₂)q·d`。普通门控只替换 Gaussian 前件。历史 V1/V5 与 Z0 同日期参考一并列出，但 V1/V5 的训练资料分配和求解过程不同，不能把直接差值全归给“分阶段”一个因素。V6 失败的辅助表示没有传入本轮。

此处“较晚专家段”避免用共同模型已拟合过的同一批标签来定义专家残差，也避免不同时间前缀的编码器潜坐标不一致。不过它牺牲了共同模型可用的训练日数，属于本方案自身的成本。九组每组均对共同模型做内外层训练，再分别训练 Gaussian 和普通门控局部阶段；没有见结果后扫描切段比例、惩罚或种子。

## 开发期结果

神经模型先按每个种子的 378 个不重复目标日计算 pooled 指标，再平均三个种子。Z0 为确定性参考。

| 方法 | pooled RMSE | pooled MAE |
| --- | ---: | ---: |
| **Z0** | **0.009431** | **0.006290** |
| V7 共同预测 | 0.009443 | 0.006407 |
| V7 分阶段普通门控 | 0.009449 | 0.006413 |
| 原 V1 Gate2 | 0.009456 | 0.006353 |
| V5 Gaussian 共享／局部 | 0.009462 | 0.006336 |
| 原 V1 LSTM3 | 0.009473 | 0.006387 |
| 原 V1 Fuzzy2 | 0.009489 | 0.006385 |
| **V7 分阶段 Gaussian** | **0.009489** | **0.006451** |

V7 Gaussian 相对同训练共同预测的 RMSE **恶化约 0.49%**，相对 Z0 **恶化约 0.62%**；和原 V1 Fuzzy2 几乎相同，但 MAE 较差。三个折的平均 RMSE 均未超过同训练共同预测，也均未超过 Z0；九组折／种子配对中对共同预测 **0/9 获胜**。普通门控总体更接近共同预测，但 pooled RMSE 也恶化约 0.06%，仅 3/9 配对优于共同预测。

| 开发折 RMSE | Z0 | V7 共同预测 | V7 Gaussian | V7 普通门控 |
| --- | ---: | ---: | ---: | ---: |
| 第一折 | 0.009828 | 0.009831 | 0.009832 | 0.009829 |
| 第二折 | 0.007270 | 0.007373 | 0.007448 | 0.007383 |
| 第三折 | 0.010787 | 0.010748 | 0.010817 | 0.010758 |

内层停止段在 9 组中选择保留 Gaussian 局部项 **4 组**，普通门控 **5 组**；其余组输出与共同预测相同。四个获内层接受的 Gaussian 局部项，在各自外层评价均使 RMSE 上升。这是“短停止段选择的局部关系未跨时间保持”的直接观察，尚不能把原因唯一归为 Gaussian 表达方式：局部段样本更少、残差本身可能难预测、市场时段变化也都可能参与。

Gaussian 的平均最大规则权重约 0.910，局部输出 RMS 约 0.000887；普通门控分别约 0.605 与 0.000334。Gaussian 前件形成较清晰的权重划分，却没有带来有效局部分工。不能仅凭规则分离程度或内层最小误差宣称可解释或优化。已保存每个日期的共同项、局部项、规则权重与两个专家预测，混合关系的数值最大误差约 5.5×10⁻¹⁰。

## 决定与解释边界

预先设定的候选条件要求 Gaussian 同时相对共同预测和 Z0 的 pooled RMSE 至少降低 1%，至少两个开发折改善、至少 6/9 组配对胜出、MAE 不比 Z0 差超过 1%，并至少六组采用非零局部项。本轮**全部未达到**；约 3% 的项目实质改善资源目标也未达到。这两个百分比是团队的筛选标准，不是老师的硬性要求或统计显著性结论。

因此停止这个固定的 **75%/25% 时序校准 + 10 epoch 共同学习 + 40 epoch 局部学习**版本，不据本轮结果反调分段比例或惩罚，也不从本轮 Gaussian 出发继续联合微调。V7 只检验这一种分阶段实现，不证明所有局部专家方案无效。它与 V6 共同提示：在目前的开发数据和目标上，表征重建与局部残差拟合都还不能稳定提高完整预定模型；后续若继续，应另立更贴近预测目标的单因素假设或先处理时间选择不稳定，并正视多轮开发筛选偏差。
