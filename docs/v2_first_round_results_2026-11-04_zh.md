# 第二版第一轮 A+B 开发比较：H1 简单基线与 H3 局部损失

**日期：**2026 年 11 月 4 日。**结论类型：**已查看过第一版最终测试之后提出的**开发期探索结果**。实验仅使用原三个开发验证折及相同的 378 个目标日；没有重训第一版模型、打开新盲测、改动第一版最终输出，也没有把第二版结果与那 251 日最终测试重新排名。预先写定的假设、λ、α 和晋级门槛见 `improvement_hypotheses_2026-11-04_zh.md`、`v2_implementation_plan_2026-11-04_zh.md` 和 `v2_experiment_contract_2026-11-04.json`。

## 实现与完整性

H1 用每折外层训练标签计算 `MeanTrain`，并把相同 `20×6` 特征展平为 120 维做 Ridge。Ridge 仅在内层停止段选 `α∈{0.1,1,10}`，随后在完整外层训练集重拟合；三折共 12 次小型拟合。三个折均选 **α=10**。这是固定网格的上边界，因此本轮不能断言“所有适当正则化的线性模型都无效”；更宽的网格只能作为新立项的事后探索。

H3 复用完全相同的原 `Fuzzy2` 架构、数据、种子和优化设置，只增加固定 **λ=0.1** 的局部专家训练项；内层早停仍使用混合输出 MSE。执行前，`λ=0` 的新训练路径在 `validation_1/seed_11` 复现第一版最佳 epoch **6**，原始预测最大差为 **0**。正式 H3 做了 **9 组运行、18 次内层／外层拟合**；记录的内层与重拟合时间合计约 **7.66 秒 + 2.02 秒**（不含数据加载及分析）。所有 H3 导出通过完整日期键、两规则权重和混合输出恒等式校验。

H1 初次汇总遗漏了单独生成、未存放在 `output/development/predictions.csv` 中的确定性 `Z0`。在 H3 运行**之前**，我们从**同一份 H1 预测**重算比较表，未重新拟合 Ridge；`output/v2/h1/analysis_correction.json` 保留了错误原因、原预测哈希和更正记录。修正后的固定参考为 `Z0`，并在 H3 `run_plan.json` 中保存其文件哈希。更正使 H1 源文件整体哈希变化，但 Ridge 拟合逻辑未改；用当前源码对三个外层折作**仅用于复现的**重拟合，与原保存预测的最大差仅约 **1×10⁻¹⁶**，见 `output/v2/h1/reproduction_check.json`。这些三次核对拟合不计入 H1 的 12 次研究拟合。

## H1：输入是否支持超过简单模型的逐日预测？

| 开发期方法 | 三折 pooled RMSE（种子均值） | pooled MAE |
| --- | ---: | ---: |
| `Z0`：零收益／价格不变 | **0.009431** | **0.006290** |
| `MeanTrain`：各折训练期标签均值 | 0.009444 | 0.006328 |
| 原非高斯 `Gate2` | 0.009456 | 0.006353 |
| 原压缩头 `LSTM3` | 0.009473 | 0.006387 |
| 原 `Fuzzy2` | 0.009489 | 0.006385 |
| 原普通 `LSTM32` | 0.009624 | 0.006518 |
| 新 Ridge | 0.009956 | 0.007007 |

`MeanTrain` 几乎等同于 `Z0`，Ridge 在三个折的 RMSE 都更高；原神经模型也没有稳定超过零收益参考。**本轮没有观察到足以支持增加当前结构复杂度的稳定逐日信号。**这只针对固定的六特征、下一收盘收益目标、既定 Ridge 网格和这三个已查看的开发折；不能证明 SRT 根本不存在可预测关系。

## H3：局部损失是否修复专家抵消并改善预测？

| 方法 | pooled RMSE | pooled MAE |
| --- | ---: | ---: |
| 固定参考 `Z0` | **0.009431** | **0.006290** |
| 原 `Fuzzy2` | 0.009489 | 0.006385 |
| `Fuzzy2 + local loss` | **0.009505** | **0.006400** |

H3 比固定 `Z0` 的 RMSE **高约 0.79%**，MAE **高约 1.75%**；相对原 `Fuzzy2` 的 RMSE 也略高。三个折的**种子平均** RMSE 均比原 `Fuzzy2` 高；九个同折、同种子的配对只在 **4/9** 组改善，低于预设的 6/9。相对 `Z0` 的折均值改善数是 **0/3**，与至少两个折改善、pooled RMSE 降低至少 1% 的晋级门槛相差明显。因此 H3 **没有形成预测优化候选**。

机制上，局部损失确实改变了一部分专家参数：九个配对运行的平均贡献抵消率从约 **73.6% 降到 59.9%**，九组均下降；两个专家相反符号的平均比例从约 **99.8% 降到 90.3%**。但平均最大规则权重仍约 **0.531**（原约 0.533），没有评价日超过 0.8，规则并未因此形成明显选择性。预测标准差与真实标准差的平均比例从约 **3.5% 升到 4.6%**，仍然很小，也没有改善总体误差。

按各运行**外层训练集**的规则权重 75% 分位数定义高激活区后，规则 1 在九组中有 **7** 组达到至少 20 个评价日，其中 **6** 组该专家 MAE 小于另一专家；规则 2 只有 **3** 组达到 20 日，其中仅 **1** 组具有局部优势，另有一组高激活评价日为 **0**。没有一个折／种子组合同时显示两条规则各自有合格的局部优势。因此不能把“抵消减少”解释成两名市场专家成功分工；预设局部专长门槛亦未通过。

## 决定与边界

**第一轮 A+B 的判定：不晋级。**H1 的简单模型没有发现强信号；H3 的单一局部损失减弱了数值抵消，却未提升预测，也未形成对称而稳定的专家专长。按预先写定的停止条件，本轮**不继续搜索多个 λ，也不因 H3 预测失败而调整交易阈值或运行新的交易晋级比较**。保留 H3 作为有解释价值的负结果。

若下一轮仍希望寻找信息，优先考虑 H2 的**两组独立 OHLCV 增量**，并先用简单对照筛选；这是新探索，不与本轮同时归因。另一个更小的 H1b 问题是：三折 Ridge 都选到 α 网格上界，是否需要一次单独登记的更强正则敏感性检查。若课程重点转向解释性，可在单独分支评估 H4 可观察波动率前件；若重点是交易收益，则 H5 必须重建标签完成时间和执行时域契约。任何新候选都需要真正未用于选择的数据，才能讨论独立测试改进。

**可复核文件：**`output/v2/h1/`（预测、三折 α 选择、更正及固定参考）、`output/v2/h3/`（九组预测、case/rule、训练曲线和规则阈值）、`output/v2/analysis/`（同日期比较、局部误差、机制配对及 `decision.json`）。checkpoint 是本机未纳入 Git 的训练产物；CSV、manifest 与运行代码构成可审阅证据。
