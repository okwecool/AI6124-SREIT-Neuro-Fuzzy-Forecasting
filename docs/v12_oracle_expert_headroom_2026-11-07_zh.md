# V12：原 Fuzzy2 双专家的事后最优混合诊断

**日期：**2026-11-07。**性质：**只读原 V1 开发期已保存的 Fuzzy2 预测、三维 case 和两条 rule 输出；不重新训练，不使用已经查看的最终期，不修改原课程主模型。运行前约定见[合同](v12_oracle_expert_contract_2026-11-07.json)。

## 问题与计算

原模型每日输出两个专家的下一日原始收盘对数收益预测 `e1,e2`，实际模糊权重为 `a,1−a`。本诊断固定两个专家输出，**事后看到真实收益 `y`**，计算当日误差最小的凸组合：

```text
a_oracle = clip((y − e2) / (e1 − e2), 0, 1)
y_oracle = a_oracle·e1 + (1−a_oracle)·e2
```

当两专家相等时取 `a_oracle=0.5`。这个 oracle 使用了评价标签，只是“如果完美知道应如何路由”的**不可实现误差下界**，不是模型预测，也不能用于课程性能比较或交易。另计算事后选误差较小的单一专家（hard oracle）、平均混合、两个独立专家以及零收益基线，区分专家的潜在互补与实际门控能力。

## 结果

每个种子在原三个开发折共 378 个相同日期上计分，再对种子平均。零收益为确定性方法，不把三个种子当作独立市场样本。

| 输出 | 种子平均 RMSE | 种子平均 MAE | 含义 |
| --- | ---: | ---: | --- |
| 零收益 `Z0` | **0.009431** | **0.006290** | 可实现简单基线 |
| 原 Fuzzy2 实际混合 | 0.009489 | 0.006385 | 可实现的保存模型 |
| 固定 0.5／0.5 混合 | 0.009500 | 0.006401 | 与实际门控接近 |
| 单专家 1／2 | 0.009950／0.009955 | 0.006928／0.006916 | 各自都差于零收益 |
| **事后最佳单专家** | **0.007888** | 0.004581 | 看过当天真实标签，不能部署 |
| **事后最佳凸混合** | **0.007811** | 0.004060 | 看过当天真实标签，不能部署 |

事后最佳凸混合比零收益 RMSE 低 **17.17%**、比当前实际混合低 **17.68%**；三个种子分别得到 0.007233、0.008146、0.008055，均低于零收益 0.009431。故对**这批已训练专家**，不能说“无论如何路由都没有 5% 空间”。但这只表明基于未来标签的数学空间，**不表明预测时能识别正确路由**。

关键困难很直观：三个种子分别有约 **100%、99.5%、100%** 的日期两专家给出相反符号；事后最佳权重落在边界 0 或 1 的比例分别约 **55.0%、74.9%、68.3%**。它多数时候要求在预测日前决定该采用偏涨还是偏跌的专家，接近在猜下一日方向。实际规则 1 权重的折合标准差仅约 **0.008／0.017／0.006**，事后最佳权重的标准差约 **0.410／0.453／0.449**。当前门控几乎没有作出所需的大幅切换；另一方面，这样的切换也可能完全无法由已知输入预测。事后选单专家已取得大部分 oracle RMSE 降幅，进一步验证主要差别来自**看过标签后挑选方向**，而非精细的模糊插值。

## 判断与下一步

这次诊断**没有取得任何实际模型增益**。它排除了“固定专家的凸组合在数学上不可能有明显增益”这一解释；尚未证明可观察的市场状态能够预测哪位专家会更准。原 Fuzzy2 与均分混合几乎一致，符合先前门控权重接近 0.5 的观察。继续只调 Gaussian 宽度或增加门控训练轮数，没有证据会填补 17% 的事后差距。

若继续检验可实现性，应单独设计**只用预测日前信息的路由试验**：先在每折训练段内生成不泄漏的专家预测，再以少量已知变量（如截至当日的波动、已公布利率变化）训练路由；同时比较同输入、同训练预算的普通门控和固定混合，按时间向前评价。不能把本轮事后 `a_oracle` 当作评价期输入，也不能在看过评价标签后命名规则。考虑到开发折已经反复查看，即使路由试验取得提升，也仍需要新的未用日期或其他标的独立确认。
