# 第二版改进假设清单

日期：2026-11-04。状态：**实验前讨论稿，仅定义假设与决策规则，尚未执行新实验。** 本清单依据现有冻结结果和新增事后诊断，供决定后续研究范围使用；不替代 v1.2 实验协议，也不把任何改动预先称为优化。

## 1. 要解决什么问题

第一版已经完成可复现的模型比较，但没有建立稳定预测增益、交易价值或市场状态解释。第二版应分别回答三个问题：

1. **信号：** 是否存在超过零收益、训练期均值及简单正则化模型的逐日预测信息？
2. **机制：** 模糊局部专家是否利用了这些信息，且比单一预测头或普通门控更有效？
3. **应用：** 在一致的可成交时间、成本和分派假设下，预测是否改善财富，而非仅仅选择现金？

三者分别评价。更多交易、更大的预测振幅、更分离的规则，以及某一个种子的较低误差，都不单独构成成功。

## 2. 已有证据与尚未证明的解释

依据：[冻结结果事后诊断](frozen_result_diagnosis_2026-11-04_zh.md)、[开发结果](development_results_2026-11-03.md)、[最终结果](final_results_2026-11-04.md)。

| 已观察到的现象 | 合理的待检验解释 | 目前不能直接下的结论 |
| --- | --- | --- |
| 最终 Fuzzy2 预测标准差约为实际日收益标准差的 1%–2.5%；三种子正预测日数为 6、0、0 | 输入对目标的信息弱，或学习主要形成固定偏置 | 把预测放大、强行增加交易就能提高收益 |
| Fuzzy2 开发期三个折的平均 RMSE 均高于各自 Z0；最终仅小幅领先 | 最终负市场均值与模型持续负偏置匹配，收益具有时段依赖性 | 模糊结构已形成稳定优势 |
| 最终两个专家每个样本上符号相反，贡献平均抵消约 70%–93%，权重接近均分 | 仅优化混合输出允许专家以抵消方式拟合，未培养局部准确性 | 抵消本身就是数值错误，或者强制分离一定有益 |
| 九次 Fuzzy2 内层运行在最佳 epoch 后继续训练，训练误差降、停止集误差升 | 泛化受限；增加轮数可能继续过拟合 | 早停轮数少必然意味着未充分训练 |
| 开发期真实收盘收益与可成交开盘收益有关联，但预测与两者的关系都弱 | 时域错位可能有影响，预测信号本身也可能不足 | 只改目标就能解决交易问题 |
| 事后区块重抽样的误差差区间跨零 | 当前微小排序没有足够稳健证据 | 模型完全等价，或未来必然无法改进 |

这些证据用于提出假设，不用于挑选在已经查看的最终测试期上表现最好的新版本。

## 3. 验证边界与统一决策规则

### 数据和实验边界

- 第一版的代码版本、原始数据快照、预测、阈值和执行记录继续作为历史基准。
- 第一轮新探索只使用原三个开发折。它们已被用于选择和分析，因此新增实验结果属于**开发证据**，不是新的无偏测试。
- 已查看的 2025-10 至 2026-09 结果仅用于解释第一版；不用于新配置、特征、目标、正则强度或种子的选择，也不在每次改动后重新排名。
- 确定候选方案后，要先冻结新协议，再使用真正未参与选方案的数据检验。新增数据的可得性、长度和市场覆盖尚需核实；很短的新时期只能作为初步外推检查。把已看过历史重新切一刀，不会产生新的盲测。
- 新输出使用独立版本目录。预测时点、标签起止时间、缺失值处理、训练内变换和评价日历写入配置；禁止覆盖第一版结果。
- 改变标签时同步改变训练标签的可用时间检查。改变输入时，对照模型使用相同信息；改变有效样本时，双方在共同日期重新比较。

### 候选晋级规则

以下数值是**建议采用的开发期预算门槛**，不是统计显著性定义、课程硬性规定或对效果的保证。执行前固定；不能见到结果后降低门槛。

**预测候选：** 同一标签、同一日期上，相对于该任务最强的必要对照，三种子平均 pooled RMSE 相对下降至少 1%，且至少两个开发折的种子平均 RMSE 改善；与可训练对照的九组折/种子配对中至少六组改善。平均 pooled MAE 不恶化超过 1%，逐折差值全部保留。种子共享日期，不视为九个独立市场实验。

必要对照包括 Z0、仅训练标签均值、Ridge；模糊改动还必须比较相同信息的 LSTM3 和 Gate2。早期筛选只与部分对照比较时，只能称“值得补全实验”。

**局部专家候选：** 先看混合预测是否通过预测门槛，再检查各规则训练期定义的高激活区域。在有足够样本的区域，激活专家应反复优于另一专家。每区域少于 20 个评价日标为探索性描述，不据此命名专家；还需在至少两个折看到两个专家各自的局部优势。20 日只是避免用极小子集作解释的最低筛选数，并不意味着统计充分。规则更分离但误差不改善，不算预测优化。

**交易候选：** 在固定 10 bps 成本、同一资金与信息规则下，比较三个开发折的复利财富，以及现金、动量、始终持有和原模型策略；另报 0/20 bps、最大回撤、持仓时间与换手。只有超过三个无模型参考中的最佳期末财富、至少两个折优于动量，才进入“交易增益待验证”名单。若只降低风险，则另称风险控制候选，不宣称获利改善。不能靠挑种子或零交易现金结果通过。

每项候选均记录成功与失败。小于门槛的变化可报告为小幅变化，不继续包装成实质优化。

## 4. 假设与最小实验

### H1 · 最高优先级：现有输入的收益信号主要可由简单偏置或线性关系解释

**目的：** 先明确是否值得继续为当前数据/目标增加模型结构。

**最小实验：**

- 增加训练期标签均值预测，每折单独计算，禁止使用评价期均值。
- 增加 Ridge：将同一 `20×6` 历史展平，使用训练内标准化；正则强度固定候选 `{0.1, 1, 10}`，仅以内层停止区间选取，随后完整外层训练重拟合。损失和报告仍采用原始下一日收盘对数收益。
- 比较已有 Z0、LSTM32、LSTM3、Fuzzy2、Gate2，按共同开发日期查看误差、预测均值/幅度、正预测比例、真实/预测相关性及各折的偏置方向。

**预期成本：** Ridge 为 3 折 ×（3 次内层候选拟合 + 1 次外层重拟合）=12 次小型线性拟合；均值预测无迭代训练，神经模型复用原开发预测。Ridge 为确定性模型，不人为复制三个种子。

**支持假设：** 简单均值/Ridge 已达到或超过复杂模型，或所有模型均无法稳定超过 Z0。说明当前证据不足以支持复杂结构的价值，但不能证明不存在任何非线性信号。

**反对假设：** 复杂模型在多个开发折稳定超过简单对照，并具有一致的逐日信息，而不是仅固定均值更接近当期均值。

**放弃/转向条件：** 如没有稳定的输入信号，停止广泛架构和超参数搜索，转 H2；即使表现很弱，也允许做一次 H3 来检验本项目最核心的专家训练假设。

**交付物：** 简单模型比较表、逐折偏置/振幅图、内层参数选择记录及“继续结构研究 / 优先输入研究”的决定。

### H2 · 高优先级：输入缺少与下一日变化有关的价格形成和交易活跃度信息

**目的：** 检验可获得的新信息是否比增加网络复杂度更有价值。SORA/STI 的现有边际贡献很小，不能默认增加来源数量就有收益。

**最小实验：** 先使用现有 OHLCV 数据定义两个独立增量组，分别加到原六特征上，首轮不同时加入：

- A 组：截至 `t` 已知的隔夜收益 `log(O_t/C_{t-1})`、日内收益 `log(C_t/O_t)`、日振幅 `log(H_t/L_t)`。前两项之和已有收盘收益，新增的是分解信息，并非三个完全独立信号。
- B 组：令 `v_t=log(1+Volume_t)`，加入 `v_t−mean(v_{t−20:t−1})` 和 `mean(v_{t−4:t})−mean(v_{t−9:t−5})`，分别表示相对过去活跃度的偏离和两个连续五日区间的变化。有效的零成交量映射为 0；缺失成交量不能当成零，负成交量视为数据错误。所有窗口只到当前日为止。

首先仅用 H1 的 Ridge 策略筛选 A/B，每组保持同样的内层正则网格。如果有方向一致的改善，再对入选的一组使用 LSTM3、Fuzzy2 和 Gate2 的三折三种子比较；所有模型都获得新增信息。

**评价：** 统一预测门槛；同时确认改善没有完全来自少数异常价格日或样本删选。发现缺失值时按预先定义的有效日期交集比较，不以未来数据插值特征。

**放弃条件：** 两组对 Ridge 均无跨折改善，则停止当前廉价筛选路线，不据此断言特征对所有非线性模型无用。进入更贵的神经实验需另写理由；不再滚动增加大量技术指标。

**后续而非首轮：** 多尺度趋势、同市场 REIT 因子或其他标的，均需新增信息时点/覆盖审计和独立对照。不得因现有测试期走势而挑选来源。

### H3 · 高优先级、首选结构实验：混合输出损失没有约束专家的局部准确性

**目的：** 检验当前大量专家抵消能否通过局部预测约束改善，而不仅是让权重图更好看。

**最小改动：** 保持原输入、编码器、两条规则、初始化、优化器和时间划分，只加一个局部专家误差项。以标准化标签计算：

```text
L = MSE(y, Σ_k α_k e_k) + λ L_local
L_local = (1/K) Σ_k [Σ_i stopgrad(α_ik) (e_ik − y_i)²
                    / (Σ_i stopgrad(α_ik) + ε)]
首轮固定 λ = 0.1，ε = 1e−8；λ=0 使用原 Fuzzy2 对照。
```

`stopgrad` 表示局部损失通过权重分配样本，但不通过这条路径直接更新门控；全局 MSE 仍训练门控。专家和共享表示仍可从局部损失收到梯度。这是待检验设计，不是从诊断中推导出的唯一正确损失。其风险是两个专家反而收敛到同一预测器，因此不加“强制不同输出”或“强制均衡”来保证表面成功。

**最小规模：** 一个新增配置 × 3 折 × 3 种子 =9 组运行、18 次内层/外层拟合。局部损失参与训练；早停仍按内层混合输出 MSE，保持评价目标一致。对照原 Fuzzy2、LSTM3、Gate2 及 H1 简单模型。

**评价：** 整体 RMSE/MAE、训练定义区域的专家误差与样本数、贡献抵消率、专家预测差异、权重分布。抵消率必须与绝对贡献一起报告，避免混合输出接近零时比例失真。

**晋级：** 同时通过预测门槛与局部专家门槛，才支持“局部训练带来有用分工”。如果仅解释性改善，则作为单独的解释性结果。

**放弃条件：** 只有抵消下降，整体误差没有改善；或者两个专家变成相同预测器；或者局部优势只在一个小样本区域出现。首轮失败后不立即搜索大量 λ。先决定是否转 H4。

### H4 · 条件性备选：潜变量前件使规则难以对应稳定可观察状态

**触发条件：** H3 不能形成有用分工，或希望把课程贡献集中在可解释性。首轮不与 H3 同时改变，避免无法归因。

**最小改动：** 保留 LSTM 三维表示供两个仿射专家预测；门控改为只读取截至 `t` 的过去 20 日波动率。两条高斯前件表示相对低/高波动，中心取训练内标准化波动率的 25%/75% 分位点，宽度固定为 `max(0.1, 0.5×训练IQR)`，每次内层/外层拟合分别估计并固定。首轮不用趋势与波动率的多组合搜索。

**公平对照：** 原 Fuzzy2、LSTM3，以及同样只读取该波动率的普通两专家门控模型。不能只与原 Gate2 比较后把优势全归因于高斯形式，因为前件的信息约束也改变了。

**评价：** 与 H3 相同的误差和局部专家标准；检查两种状态的覆盖、尾部支持与跨折稳定性。固定且可命名的前件，不保证后件真有专长。

**放弃条件：** 波动率分组不能反复产生局部误差优势，或整体预测恶化而只有解释文字变得容易。若保留为准确性—解释性权衡，必须明确取舍，不称预测优化。

**预算：** 新模糊前件和匹配的普通门控共 2 配置 × 9 组 =18 组运行、36 次拟合；仅在决定采用这条研究分支后安排。

### H5 · 独立交易分支：预测时域与可成交收益对齐后，信号更有用

**触发条件：** 优先目标明确为交易应用，且能够完成新标签与时序契约。它改变任务，应独立命名，不与原收盘预测的 RMSE 直接排名。

**最小实验：** 在 `t` 收盘后预测 `log(O_{t+2}/O_{t+1})`，与下一开盘进入、再下一开盘退出的价格区间一致。先保持原六特征和三折开发结构，比较 Z0、训练均值、Ridge、LSTM3 和一个选定的模糊版本；不同时更改特征、损失和交易策略。原收盘模型的策略作为应用参考。

**必须先定义的时间规则：**

- 每个样本存储 `forecast_time`、`entry_time`、`label_end_time`。这类标签需要等到 `t+2` 开盘才可得。
- 内层及外层训练均只使用在评价起始预测时点之前已完全实现的标签；不能直接沿用原来仅按下一收盘目标日切分的行号。
- 标签需要的任一开盘缺失时，不填补标签；在相同可评价日期上比较所有预测模型。交易端继续使用预先固定的缺报价不交易规则；缺预测日的持仓处理须在新协议中定义。
- 原始开盘标签对应价格收益任务；含分派财富另列，并保留正确权益/付款记账，不能把二者当成完全相同的目标。

**评价：** 同目标预测基线，以及统一交易门槛；主策略先固定 `预测>0`、10 bps，0/20 bps 敏感性。首轮不新增阈值搜索。

**放弃条件：** 收益预测和净财富均未跨折改善；或只有零成本下改善，10 bps 后消失；或所谓改善来自更长时间持有现金。此时不能把所有失败归因为原始时域错位。

**后续：** 5 日等更长时域只作为另一个方案讨论，需处理重叠标签、训练边界清除、重叠持仓与样本依赖，不在第一轮同时扫描多个 horizon。

### H6 · 低优先级：当前容量或优化设置不适合小样本

已有早停证据降低了“只增加轮数”的优先级。如果 H1/H2 显示可预测信息而神经模型仍无法利用，可单独试 **32→8 隐藏单元**，并同步比较相同编码器的 LSTM3、Fuzzy2。若要测试更小学习率，则另一次只改学习率，不与容量同时改变。

评价仍是共同开发日期的泛化误差和稳定性。训练误差下降但验证不改善则停止；不取消早停来强行跑出较低训练误差。Attention、更深 LSTM、更多规则、大规模超参数搜索暂不列入最小计划。

## 5. 建议执行顺序与预算

| 阶段 | 要做的事 | 决策与停止点 |
| --- | --- | --- |
| A：最低成本信号检查 | H1，12 次小型 Ridge 拟合及均值参考，复用旧神经预测 | 明确当前结构是否超过简单偏置/线性信息；无稳定优势则不展开广泛调参 |
| B：一次核心机制实验 | H3 的一个 λ 配置，9 组运行、18 次拟合 | 不同时加新特征；无整体/局部收益则停，不扩大 λ 搜索 |
| C：依据 A/B 选一个分支 | 信号弱选 H2；解释性优先且 H3 失败选 H4；交易目标优先选 H5 | 每次只开一个分支，并写清预算、标签和对照；不做全部组合的笛卡尔积 |
| D：补齐候选比较 | 对一个候选补齐必要对照、三折三种子和成本敏感性 | 未达到开发门槛则保留负结果；达到也只称候选 |
| E：独立验证 | 冻结新方案后，核实并采用未参与选择的新数据 | 新数据不足则报告探索结果，不宣称已经证实优化 |

**建议第一轮范围仅为 A+B：12 次小型线性拟合 + 18 次神经拟合。** 与原 126 次拟合相比，新增范围可控，并直接检验“有没有超出简单偏置的信息”和“局部损失能否改善专家抵消”两个关键问题。其计算时间须由实际运行记录，不能仅按旧耗时推算。

| 公平对照 | 同信息、同目标、同日期及同训练选择预算的比较对象 |
| 冻结设置 | 种子、参数、损失、早停、评价、成本、缺失处理 |
| 资源预算 | 新配置数、预计拟合次数、停止条件 |
| 结果 | 每折每种子、pooled 指标、偏差/方差、规则局部表现或净财富 |
| 决定 | 放弃 / 继续补对照 / 开发候选；理由及是否达到预设门槛 |
| 结论边界 | 开发探索 / 已查看历史的解释 / 新的独立验证 |

所有模型改善都应最后回答：“相对什么对照，在什么数据与成本条件下，改善了多少，是否稳定，付出了什么代价？”目前最重要的是让下一轮实验能够回答原因，而非只产生一个更好看的最小误差数值。
