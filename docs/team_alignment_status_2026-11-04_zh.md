# AI6124 项目现状与下一步：Ryan–Destin 对齐稿

**日期：**2026-11-04
**用途：**组内讨论稿，不是最终报告或 slides。**版本状态：**第一版冻结测试已完成；第二版优化实验属于开发期探索。下文区分已经测得的结果、课程明确要求和我们的判断。

## 1. 一句话结论

我们已完成一个可复现的 **LSTM → 3 维潜在特征 → 两条 Gaussian 模糊规则 → 两个局部专家**的 S-REIT ETF 收益预测实验，以及普通模型、时间顺序验证、最终测试和交易比较。原模糊模型**尚未证明实质优化**。后来找到一项在开发期超过零变化基线的改进：利用预测前已公告的 ETF 分派信息，RMSE 下降 **2.76%**；但这项收益属于新增信息，模糊网络本身仍未超过该基线。因此目前可以展示“完整实验 + 有边界的优化线索”，不能说“模糊模型已经稳定优化预测或交易”。

## 2. 当前问题、数据与模型

- **目标：**预测 CSOP iEdge S-REIT Leaders Index ETF 的 SGD 交易柜台 `SRT.SI` 在下一交易日的**原始收盘对数收益率** `log(C_{t+1}/C_t)`，再用 `C_t exp(ŷ_t)` 还原下一收盘价。SRT 是可交易 ETF，**不是**其跟踪指数的点位。当前目标也不是直接预测买卖标签。
- **基本输入：**截至预测日收盘可知的 20 个 SRT 交易日 × 6 个特征：SRT 日收益、5 日动量、20 日波动率、STI 已知收益、按公布日对齐的 SORA 水平和变化。已有 **1,182** 个有效窗口。
- **核心结构：**一层、32 隐藏单元的 LSTM 将历史压缩为 `h`，再投影为 `z∈R³`。两条 Gaussian 规则按 `z` 的距离产生归一化权重 `α₁,α₂`，两个仿射专家给出 `e₁,e₂`，最终预测 `ŷ=α₁e₁+α₂e₂`。模糊层接收的是每次预测的**三个学得的数**，并未修改 LSTM 内部的输入门/遗忘门。
- **对照：**零收益／价格不变 `Z0`、普通 `LSTM32`、同样使用三维表示的 `LSTM3`、非 Gaussian 双专家门控 `Gate2`；第二版补充训练期均值和 Ridge。这样才能区分表示压缩、双专家结构及 Gaussian 门控各自可能的贡献。
- **新增资料：**开发期三次 SRT 分派的 SGX 公告记录，以及同类纯 S-REIT ETF `CLR.SI` 的固定日行情快照（2,243 行）。CLR 是另一只 ETF，不能把其历史直接拼成 SRT 的更长历史。

## 4. 效果：哪些确实改善，哪些没有

以下是**同一目标**的原始收益 RMSE；神经模型为三种子平均。开发期与最终期是不同市场时段，只能在同一列内比较方法，不能用两列数值大小判断进步。

| 第一版方法 | 开发期 378 日 RMSE | 冻结最终 251 日 RMSE | 最终 MAE |
| --- | ---: | ---: | ---: |
| `Z0` | **0.009431** | 0.006377 | **0.004547** |
| `LSTM32` | 0.009624 | 0.006384 | 0.004651 |
| `LSTM3` | 0.009473 | 0.006355 | 0.004593 |
| `Gate2` | 0.009456 | 0.006353 | 0.004582 |
| `Fuzzy2` | 0.009489 | **0.006349** | 0.004595 |

`Fuzzy2` 在最终 RMSE 比 `Z0` 低约 **0.44%**，但开发期更差、最终 MAE 也更差；与 `Gate2/LSTM3` 的差距极小。最终主交易政策下 `Fuzzy2` 平均期末财富约 **0.999**，现金为 **1.000**；两个种子零交易。规则平均最大权重接近 0.5，未观察到稳定的“强市／衰退市场”局部专家。故 **0.44% 不是有说服力的优化，更不是盈利或可解释状态的证据**。

第二版在相同开发日期上做了有记录的补充实验：

| 探索 | 结果与解释 |
| --- | --- |
| 简单模型与局部专家损失 | 训练均值 RMSE 0.009444；原网格 Ridge 0.009956；`Fuzzy2 + λ=0.1` 局部损失 0.009505。局部损失减弱专家输出抵消，却未提高整体预测，也没有稳定的双专家分工。 |
| 更强 Ridge、OHLCV、五日时域 | 强正则 Ridge、分别新增价格分解或成交量特征，都未胜过 `Z0`；另设的五交易日任务中 Ridge 亦比零收益基线差约 7.06%。五日任务的误差数字不能与一日任务直接比较。 |
| **已公告分派 `DivSchedule`** | 用预测前公布的金额和除息日作确定性价格调整，一日任务开发期 RMSE **0.009170**、MAE **0.006148**；相对 `Z0` 分别改善 **2.76%/2.26%**，3 折中 2 折改善。但 378 日仅有 **3 个**除息目标日，这是**开发期的信息增益**，尚无独立验证。 |
| 模糊残差与 CLR | Fuzzy2 预测扣除分派后的剩余收益，再加公告调整，RMSE **0.009232**，仍比 `DivSchedule` 差 **0.67%**；加入 CLR 同日收益的七输入 Ridge 比相同六输入 Ridge 好 **1.24%**，最终 RMSE **0.009197**，仍比 `DivSchedule` 差 **0.29%**。不能把公告带来的改善归功于模糊结构。 |

**我们的判断：**老师很可能希望看到受控的“标准模型 → 改进模型”比较、改进机制与适用条件，而不仅是一个复杂模型或一张最优数字表。负结果仍可如实分析，但课件**没有**规定“负结果自动不合格”，我们也无法预测最终评分。当前方案在方法与测试规范上匹配课程；在“模糊模型带来可重复、实用的优化”这一较强目标上仍未达成。原拟标题中的 *interpretable ... under different market regimes* 也超过现有证据，最终标题应待规则语义验证后再定。

## 6. 建议两人对齐的下一步

1. **先统一成功标准。** 若目标是“预测流程相对 `Z0` 改进”，公告分派是一个开发期候选；若目标是“模糊网络自身优于标准模型”，必须进一步超过同信息的 `DivSchedule`、`LSTM3` 和 `Gate2`。目前后者没有成立。
2. **确定一个新的、有限的优化实验。** 优先核实 CLR 较长历史能否用于一个独立定义的 REIT 目标或辅助预训练，再固定同目标、同信息、同日期的非模糊对照和未参与选择的评价期。CLR 与 SRT 跟踪不同指数，不能直接续接价格。若继续用 SRT，先把已公告分派作为所有方法共同可用的信息；不继续扫描大量 λ、规则数或交易阈值。
3. **保留证据边界。** 原 251 日最终期已查看；不能为第二版反复测试或重命名为盲测。新方案需要新的独立数据/时间段，若暂时没有，只能报告开发期候选。交易收益还必须用一致的执行时点和成本重新评价，不能由 RMSE 改善推断盈利。
4. **分工和文书。** Ryan 可继续负责数据来源、时间边界、代码和受控实验；Destin 可同步核对方法与文献、课程 rubric、Notebook/图表/slides 的叙述。双方共同核对关键表格、限制和最终上传要求。现有 Notebook 与 slides 只反映第一版冻结结果，**没有纳入第二版候选**，修改展示须等研究结论稳定。
