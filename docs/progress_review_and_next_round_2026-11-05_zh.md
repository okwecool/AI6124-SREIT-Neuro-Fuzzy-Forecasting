## 1. 结论

工程和实验纪律已有明显进展，但**模糊模型带来的实质优化仍未成立**。当前最强的开发期预测器是只用已公告分派的 `DivSchedule`。其相对零收益的 **2.76% RMSE 改善全部来自三个除息目标日**；其他 375 日，两种预测完全相同。这是有效的信息利用结果，但证据集中、还没有独立验证，也不是模糊机制贡献。

下一轮建议保留 SRT、下一日原始收盘收益和原开发折，测试一个更明确的问题：**在公告基线之上，经过分派校正的低维历史信息，能否支持有用的状态条件残差？**先用最多 72 次小型线性求解区分信息处理、输入压缩和模糊分区的贡献。通过后才考虑接入神经编码器；没有通过则收束这一预测路线。优先级高于继续增加均线、利率指标、规则数或尝试多个损失权重。

## 4. 需要修正或补足的地方

### R1：最新研究尚未形成完整课程交付，重打包脚本也遗漏 V2 输出

**优先级：交付前必须处理。**当前最终 Notebook 和 slides 都没有 `DivSchedule` 或 2.76% 这项结果；旧 ZIP 没有 V2 文件。两份组内对齐稿仍记录 31 项测试，尚未反映新增趋势/利率实验。

更具体的问题是 [`package_handoff.py`](../src/tools/package_handoff.py) 的 `DIRECTORIES` 没有 `output/v2`。现在只重跑打包，会带入新增 V2 源码和文档，却仍缺少其保存结果。应在研究结论稳定后形成一个新版本包，纳入 V2 必要预测、分数、合同和诊断，排除 checkpoint，并检查文档引用的文件均在包中。旧 V1 包保留为历史快照。

最终 Notebook/slides 应明确区分：V1 事前冻结测试、V2 事后开发探索、新信息贡献和模糊模型贡献。不能直接用 V2 开发数字替换 V1 最终数字。旧手册中“final holdout is reserved”的句子也应更新为已经完成冻结评价的事实。

### R2：分派校正只进入标签和长均线，基础输入仍含机械性价格跳变

**优先级：下一轮最值得检验的表示问题，不是已证实的性能缺陷。**[`run_residual_fuzzy.py`](../src/v2/run_residual_fuzzy.py) 扣除了历史标签中的分派调整，但输入仍来自原 `data.x`；[`prepare_dataset.py`](../data/prepare_dataset.py) 的前三列是原始价格收益、五日动量、二十日波动率。CLR 筛选也用原始收盘收益。

例如 2025-01-20，SRT 原始对数收益约 **−2.740%**，包含当日分派的对数总收益约 **+0.270%**；当日结束的二十日波动率从原始口径的 **0.908%** 降到分派总收益口径的 **0.661%**。一次机械跌价还会进入后续多个重叠动量/波动率窗口。因此，若希望规则代表市场波动状态，需要把公司行动影响与经济回报分开。

这不属于未来信息泄漏，原始价格本身也可能有预测信息；应通过同日期、同模型的配对实验决定是否有益。不要直接删除原始口径、覆盖 V1 数据，或宣称这就是此前失败的原因。

### R3：当前收缩方法没有把最强基线作为可退回的零残差模型

[`fit_ridge`](../src/v2/baselines.py) 明确不惩罚截距。随着正则增大，模型趋向**训练期残差均值**，而不是零残差。神经模型沿用的目标中心化也意味着“标准化输出为零”对应训练期均值，不等于公告基线。

| 开发折 | 训练期残差均值 | 验证期残差均值，仅事后诊断 |
| --- | ---: | ---: |
| 1 | −0.000208 | +0.000859 |
| 2 | −0.000010 | −0.000698 |
| 3 | −0.000116 | +0.000736 |

两个折的均值方向相反。均值偏置只解释部分误差，不能据此保证修复后明显提高；但说明“继续增大 Ridge α”没有真正检验“必要时完全信任公告基线”。下一轮应在**原始残差零点**上收缩全部系数，并把零残差作为内层可选候选。选择零残差只代表退回基线，不计为优化。

### R4：高维线性筛选和弱选择性的模糊层仍留有未检验空间

目前 Ridge 通常将 20×6 展成 120 个系数输入；趋势组增加到 124 维，同时第一折训练窗口降至 388。它们能说明这些固定模型未通过筛选，不能排除少量历史摘要或状态条件关系。应补一个低维对照，而不是据此直接跳到更大的神经网络。

原 Gaussian 门控初始化也很宽：`z∈[-1,1]³`，两中心第一坐标为 ±0.25、宽度为 1，此时两规则的 logit 差为 `0.5*z1`，所以**初始最大权重不超过 sigmoid(0.5)≈0.6225**。训练可改变中心和宽度，这不是永久上限；但与早停较早、实际权重长期接近 0.5 的观察相容。仅增加专家局部损失没有直接解决前件分区，这也与 H3 负结果一致。

下一轮应给规则一个训练期定义的可观察前件，再检验其是否有用。不要为了得到漂亮权重而强制硬分区：高/低波动状态的存在，不能自动推出它们的**条件平均收益**不同。

### R5：重现和效果证明还需要各补一层

V2 部分 manifest 只记录主脚本和部分数据的哈希，未覆盖完整依赖。例如 CLR 筛选依赖残差标签、分派调整及 Ridge 求解模块；H9 残差标签还读取日表的分派列。不能把主脚本/窗口文件哈希等同于整个执行依赖已冻结。新实验应记录实际读取的日表、窗口、索引、折、事件来源和所有相关模块，并保存输出文件哈希及一次聚合核验入口。

另一方面，原最终期已经看过，三个开发折也经历了多轮搜索。现在再写一个合同只能约束**从现在开始的实验自由度**，无法使这些日期重新独立。CLR 更长历史能提供训练资料，但同市场、同日期的另一只 ETF 不应直接当作完全独立的市场验证；从已查看历史重新切分也不是盲测。

## 5. 下一轮主方案：公告基线上的小型条件残差

### 5.1 保持任务边界

- 目标仍为 `y_t = log(C_(t+1)/C_t)`；训练标签保持 H9 的残差定义，不改成另一个预测任务。
- 预测为 `ŷ_t = d_t + r̂_t`，`d_t` 只使用预测日前已公告的下一目标日分派。训练标签中的已实现分派属于完成的历史标签；它不能变成未来输入。
- 只使用原三开发折和相同 378 个评价日，保留原 553/679/803 个外层训练窗口。新特征如果不能保留这些日期，先停下解释数据问题，不静默改变样本。
- 本轮不加入 CLR、SGS10Y、200 日均线、新损失扫描或新交易阈值。先把原六输入的处理和模型尺度检验清楚。

### 5.2 输入校正与六个固定配置

定义截至当日已经发生的分派总收益：

```text
q_t = log((C_t + D_t) / C_(t-1))
```

校正输入仅替换原前三列为 `q_t`、最近五日 `q` 之和、最近二十日 `q` 的总体标准差；STI、已公布 SORA 水平及变化沿用原契约。这些是历史输入，**不将未来 D 输入模型**，也不使用整段回溯复权价代替点时构造。此 `q` 是总收益特征，不等同于 H9 的分派残差标签，两者用途要分别标明。

| 配置 | 输入 | 模型 | 用途 |
| --- | --- | --- | --- |
| A1 | 原六列 × 20 日，展平 | 零点收缩 Ridge | 新收缩方法下的高维参考 |
| A2 | 校正六列 × 20 日，展平 | 相同 Ridge | A2−A1 检验分派输入处理 |
| B1 | 原六列在预测日的末端值 | 零点收缩 Ridge | B1−A1 检验历史摘要取代展平输入 |
| B2 | 校正六列在预测日的末端值 | 相同 Ridge | B2−B1 检验低维条件下的输入处理 |
| C1 | 与 B1 相同 | 固定可观察前件的双规则 TSK | C1−B1 检验状态条件结构 |
| **C2，预定主候选** | 与 B2 相同 | 相同双规则 TSK | C2−B2 检验校正输入上的状态结构 |

所有模型使用相同训练标签、公告加回、内层选择和日期。B/C 的六个末端值仍含五日动量和二十日波动率，绝非只看一个交易日。A 与 B 的差异同时改变信息压缩和参数数量，不应只归因为“参数更少”。全部六配置都会报告，不能看完后任意挑一个替代预定主候选。

### 5.3 零点收缩，而不是训练均值收缩

输入由各次拟合的训练段标准化。目标残差只除以训练标准差 `s_r`，**不减去训练均值**；零输出因此对应原始残差零。标准差为零时按预先固定的回退规则处理。线性模型包括截距在内全部惩罚：

```text
min_beta mean_i[(r_i/s_r - phi_i beta)^2] + lambda * ||beta||²
```

固定 `lambda∈{0.1,1,10}`，另有不需拟合的 `r̂=0` 候选。这是按样本平均损失定义的 λ，不能与旧按 SSE 定义的 α直接等同。内层最后 15% 选择，分数并列时先选零残差，再选较大 λ；外层重新拟合缩放参数及选定模型。有限候选使用数值线性求解，不显式求逆。

**预算上限：6 配置 × 3 折 ×（3 个 λ 拟合 + 1 次外层拟合）=72 次小型求解。**若选择零残差，外层无需拟合，实际次数更少。不按种子重复确定性模型，不继续扩大 λ 网格。

### 5.4 模糊分区只检验一个清楚的机制

C1/C2 的前件均为对应输入中的二十日波动率，仍只使用 B1/B2 已有信息。分别在每次拟合的训练段将该变量标准化，以训练 25%/75% 分位数为两个 Gaussian 中心，共同宽度固定为 `max(0.1, IQR/2)`；分区不使用验证标签。若训练 IQR 为零，记录退化并回退为单一线性模型，不人为制造两个状态。

把六维标准化末端输入记为 `x`，高波动规则权重为 `a(x)`。采用：

```text
g(x) = 2*a(x) - 1
r̂/s_r = b + w'x + g(x)*(c + v'x)
```

这是两条后件 `(b+w'x) ± (c+v'x)` 的加权和，共 **14 个线性系数**；单一后件 B 只有 7 个。所有系数按同一 λ 收缩。固定前件后联合求解后件，避免两个专家通过独立随机初始化制造大幅相反贡献；它仍可能学成相同专家，是否形成有用分工由评价决定。

**归因限制：**同宽的一维双 Gaussian 归一化后，权重在数学上等价于某个线性 logit 的 sigmoid。因此这个实验检验的是“可观察状态条件的局部模型是否有用”，不能声称已经证明 Gaussian 比普通 sigmoid 门控优越，也不应把二者的等价实现当成两份独立胜利。

固定前件的 TSK 本身是一个小型模糊诊断对照，**还不是新的 LSTM 神经模糊主模型**。不直接拿它替换课程批准的混合结构。若 C2 通过，再单独设计神经编码器 + 可观察前件 + 正则化后件的版本；同时加入同输入神经线性头、同信息非模糊非线性头，区分编码器、非线性容量和规则分区。可参考 Week 4.2 的前件/后件分开学习思想，但仍需新的受控比较，不能提前承诺其收益。

### 5.5 晋级与停止

下面是本轮建议的**资源决策门槛**，不是老师要求，也不是统计显著性标准。执行前应写入机器可读合同，再固定代码/数据依赖；本审核文档本身不是已执行合同。

1. C2 的全部日期 pooled RMSE 至少比 `DivSchedule` 及六配置中的最强非模糊参考低 **1%**，并在至少 **2/3 折**分别胜过这两个参考；pooled MAE 对两者均不能恶化超过 **1%**。比较对象包括 A1/A2/B1/B2，不能只挑较弱的 B2。
2. 非除息 375 日 RMSE 相对 `DivSchedule` 至少改善 **0.5%**；单列每个除息事件，防止所谓优化只靠三个事件。该新增门槛仅用于新实验，不回头更改 H8 的结论。
3. 机制上，按各拟合训练期波动率 25%/75% 分位数固定低/高区域，记录两区域的实际样本数；至少两个折的两个区域各有 20 个评价日，并分别出现对应专家的局部 MAE 优势。样本不足只作描述；20 日不是统计充分性保证。还需报告局部混合误差、单一后件误差、权重分布、专家差距和绝对贡献，不能只展示漂亮的权重图。
4. 若零残差频繁被选中、C2 未达到预测门槛，或者只得到权重更分散而没有误差下降，**本轮不进入新的神经训练**。B2 单独有改善只能支持低维信息处理方向，不能宣称模糊改进；不自动为其再开一轮搜索。
5. 通过也只能称“开发期候选”。按日期的配对误差和分折结果用于评估稳定性；若附加 block bootstrap，应事先固定方法，并明确它不能消除多轮开发搜索偏差。真正的独立评价还需要新数据，不能重命名原最终期。

## 6. 交易、迁移学习和课程要求如何安排

### 交易价值：先对齐时域，不能靠公告跌价直接声称盈利

原目标是 `C_t→C_(t+1)`，下单最早在 `O_(t+1)`。已公告分派的机械价格调整与除息开盘时间有关；开盘时才交易的策略不能把整段收盘到收盘预测收益视为可捕获收益。原账本对分派权益的处理是合理的，不能为了制造交易改善而取消分派记账。

建议先补**已有开发数据的归因表**：将 close-to-close 变化分成 `log(O_(t+1)/C_t)` 和 `log(C_(t+1)/O_(t+1))`，另列原策略实际对应的 `O_(t+1)→O_(t+2)`，分别展示除息/非除息日。该表是描述性诊断，不能用于挑选最佳交易规则。

只有把“交易优化”另立为目标时，才新建 open-to-open 标签、标签完成时间及含分派权益的财富评价，设置现金、持有和动量对照，固定成本和缺开盘规则。该支线不与本轮 72 次求解合并；本轮没有承诺新交易优势。

### CLR 迁移：保留为后续选项，暂不作为第一优先级

本地 CLR 快照虽有 2,243 行，**截至开发截止日 2025-09-30 只有 1,992 行**；每个外层折实际允许的预训练资料还要再按该折训练时间截断。不能把完整 2,243 行都用于每一折预训练，否则源资产也会把较晚市场信息带入较早评价。CLR 当作源任务时还须核查它自己的分派、输入口径和预训练标签完成时间。

迁移可能改善表示，也可能引入不同指数的偏差；目前没有本项目证据证明前者。若以后做，最少需要同目标、同输入的从零训练/CLR 预训练配对，以及“迁移普通神经模型/迁移模糊模型”对照；不能把迁移收益归给模糊层。这比先检验原输入处理需要更多数据核对和实现，故调整为第二优先级。

### 与老师要求的对应

本轮重读了本地 Week 8 课件 PDF 第 20、21、23、26、27、32–38 页，以及 Week 4.2 第 29、32–33 页。以下是明确要求与我们的判断的区别：

| 课程重点 | 当前状态与补足事项 |
| --- | --- |
| 明确数据、混合方法、普通 AI/ML 基准；因果验证 | V1 已具备；新小型 TSK 是诊断对照，不能被包装成已经完成的新神经混合主模型 |
| 同一个 Notebook 包含代码、结果和项目报告，配套简洁 slides | V1 已具备，V2 还需并入带版本边界的补充分析；新交接包需包含 V2 实际输出 |
| 解释方法、参数作用、优缺点，结果分析不能只有数字 | H3 的负结果、公告归因、均值偏置及状态机制检验都能提供具体分析；不能给潜在专家强行命名经济状态 |
| 比较有/无预测的组合财富，策略参数只在训练数据选 | 原实验已做，但没有证明交易提升；本轮公告改进仍缺乏对应交易收益证据 |
| 额外数据/迁移用于改善的可选加分方向 | 分派信息有开发期改进证据；CLR/SGS 的加入本身不等于已实现优化，也不保证加分 |
| 方法复杂性和自己的扩展会影响评价 | 不能仅为提高分数增加复杂度，也不能因小型对照表现更好就省略批准的混合方法及其分析 |
| 修改 proposal 需老师批准（Week 8 第 21 页） | 本轮只建议在现有任务内做对照；若以后正式更换主资产、目标或主方法，应按课程要求确认，当前没有执行这种切换 |

课件没有规定必须达到某个 RMSE 改善百分比，也没有“负结果自动不合格”的条款。当前在实现、对照和实验规范上基本匹配要求；在“模糊机制稳定提升预测/交易”这一较强研究目标上仍未达成。比继续堆许多不显著指标更有价值的，是补齐机制验证、清楚解释失败原因，并把最新证据纳入最终交付。
